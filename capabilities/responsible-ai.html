Why it matters for learning

A helpful scaffold should make the next step possible without doing the reasoning for the learner. Questions and hints create space for reflection and productive struggle.

How I build it

  • I use question-led support where it serves the learning task. The learner still decides what to write or change.
  • All replies here are scripted examples. Teacher approval applies to the assessment workflows shown elsewhere; it is not claimed for every tutor reply.

Features in practice

Source: Class Studio

Question-led tutor

A student asks for help with the river investigation and receives a prepared question about the evidence, rather than a completed explanation.

Teacher control. The teacher can inspect the learner’s draft and conversation. The scripted tutor does not verify arbitrary scientific claims.

Choose a suggested prompt and send it; consider what the question asks you to think about.

Code Mate: hint-first coding help

A short hint and a guiding question help the learner reason about the robot’s blocks, sensor rule or movement.

Teacher control. Replies are local, scripted examples. The learner changes and tests the code; no live AI service or robot is connected.

Ask Code Mate about stopping, then change a sensor threshold and test the result.
